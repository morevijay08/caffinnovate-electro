# CaffInnovators

CaffInnovators is a platform showcasing electronics, IoT, and robotics projects for engineering students.

## Features
- Electronics Projects
- IoT Projects
- Robotics Projects
- Learning Resources

## Tech Stack
- React
- Vite
- Tailwind CSS
- TypeScript

## Getting Started

### Prerequisites
- Node.js (compatible with the versions supported by the project dependencies)
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Vite prints the local URL in the terminal after the server starts.

## Project Checks

Build the production bundle:

```bash
npm run build
```

Run lint checks:

```bash
npm run lint
```

Run the test suite:

```bash
npm test
```

## Contributing

1. Create a separate branch for your change.
2. Keep the change focused and review the diff before committing.
3. Open a pull request against `main` with a summary of the change and any checks you ran.
